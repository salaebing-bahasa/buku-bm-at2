# หนังสือเรียนภาษามลายู อต.2 · Buku Teks Bahasa Melayu Tahun 2

เว็บไซต์หนังสือเรียนภาษามลายู ชั้นปีที่ 2 หลักสูตรอิสลามศึกษาตอนต้น (อต.2)
เนื้อหาตรงกับหนังสือเล่ม (ไฟล์ Word) ใช้ภาษามลายูมาตรฐานทั้งหมด

เรียบเรียงโดย ผศ.มูหำหมัด สาแลบิง · สาขาวิชาภาษามลายู คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยทักษิณ

## มีอะไรในเว็บไซต์

- บทเรียน 10 บท (`pelajaran/01.html` – `10.html`): สระประสม สระ e สองเสียง พยัญชนะประสม ประโยคคำสั่งและประโยคบอกเล่า เพื่อน ห้องสมุด สัตว์และผลไม้ ของเล่น และน้ำ
- ปุ่มฟังเสียงคำศัพท์ (ใช้ระบบอ่านออกเสียงของเครื่อง)
- แบบฝึกหัดพร้อมปุ่ม “ดูเฉลย” แบบทดสอบตนเอง และบัตรคำท้ายบท
- อภิธานศัพท์พร้อมช่องค้นหา (`glosari.html`)

## วิธีแก้ไขเนื้อหา

เนื้อหาทั้งหมดอยู่ในไฟล์ `_src/data/at2.js` ไฟล์เดียว
หลังแก้แล้วให้รันคำสั่งนี้ในโฟลเดอร์หลักของ repo เพื่อสร้างหน้าเว็บใหม่ (ต้องติดตั้ง Node.js ก่อน)

```
node _src/build.js
```

ถ้าแก้คำผิดเล็กน้อย จะแก้ในไฟล์ `.html` บนหน้า GitHub โดยตรงก็ได้ แต่ถ้ารัน `build.js` ภายหลัง ส่วนที่แก้ใน `.html` จะถูกเขียนทับ

## สถิติผู้เข้าชม (GoatCounter)

เว็บไซต์นับผู้เข้าชมด้วย GoatCounter รหัส `buku-bm-at2` ดูสถิติได้ที่ https://buku-bm-at2.goatcounter.com
ถ้าต้องการเปลี่ยนรหัส ให้แก้บรรทัด `const GOATCOUNTER = ...` ในไฟล์ `_src/build.js` แล้วรัน `node _src/build.js`
