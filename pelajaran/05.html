ประโยคบอกเล่า (ayat penyata)

ประโยคบอกเล่าใช้บอกข้อมูล ลงท้ายด้วยมหัพภาค ( . ) เช่น Saya tinggal di Yala.

Latihan แบบฝึกหัด

  1. เติมคำให้ถูกต้อง [ berumur · tinggal · nama · suka ]

    1. saya Hasan.
    2. Saya sembilan tahun.
    3. Saya di Narathiwat.
    4. Saya bermain bola.
    ดูเฉลย

    Nama, berumur, tinggal, suka
